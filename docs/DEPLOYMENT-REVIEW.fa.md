# بررسی استقرار PQTunnel (فارسی)

این سند دو ایراد مهم در مسیر استقرار نسخهٔ آزمایشی را ثبت می‌کند.

## ۱. تطابق نصب‌کننده با بستهٔ Release

بستهٔ Release شامل باینری کامپایل‌شدهٔ `pqtunneld` و پوشه‌های `scripts/` و `deploy/` است، اما لزوماً سورس کامل یا `go.mod` را ندارد. نسخهٔ قبلی `scripts/install-server.sh` فقط سورس کامل را می‌پذیرفت و برای بستهٔ Release آماده نبود. نصب‌کنندهٔ اصلاح‌شده هر دو حالت را می‌پذیرد: سورس کامل با Go 1.24+ یا بستهٔ Release لینوکس هم‌معماری. قبل از نصب، گواهی سرور را با CA اعتبارسنجی می‌کند و تطابق کلید را می‌سنجد. همچنین از بازنویسی نصب موجود خودداری می‌کند.

## ۲. محدودیت فورواردینگ و فایروال

نسخهٔ قبلی زنجیرهٔ forward را با `policy accept` ایجاد می‌کرد؛ بنابراین محدودهٔ ترافیک فورواردشده را به تونل محدود نمی‌کرد. نسخهٔ اصلاح‌شده فقط برای میزبان آزمایشی اختصاصی طراحی شده است، از `policy drop` استفاده می‌کند و فقط مسیرهای بین رابط TUN و رابط WAN را برای `10.66.0.0/24` می‌پذیرد. برای جلوگیری از اثر جانبی روی میزبان‌های موجود، در صورت فعال‌بودن IPv4 forwarding، فعال‌بودن UFW یا شناسایی قوانین nftables/iptables از اعمال تغییر خودداری می‌کند.

این محافظت‌ها به معنی آمادگی تولیدی نیستند. UFW/فایروال ارائه‌دهنده، پورت TCP 8443، مسیریابی واقعی، NAT و بازگردانی باید ابتدا روی یک VPS آزمایشی مستقل بررسی شوند.

## هشدار

این فایل‌ها روی سرور واقعی شما اجرا یا آزمایش نشده‌اند. روی سرور فعلی یا سرور دارای تونل‌های فعال آن‌ها را اجرا نکنید. اجرای دستورهای نصب یا شبکه نیازمند بررسی پیکربندی واقعی و دسترسی کنسول/بازیابی است.
