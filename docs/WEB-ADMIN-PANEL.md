# پنل مدیریت وب PQTunnel

**وضعیت: آزمایشی، اختیاری و خاموش به‌صورت پیش‌فرض.**

پنل در خود فرایند `pqtunneld` اجرا می‌شود و بدون سرویس مدیریتی دارای دسترسی ریشه، وضعیت شنونده، مدت اجرای daemon، تعداد همتاها و مدت اتصال هر همتا را نشان می‌دهد. مدیر احراز هویت‌شده می‌تواند اتصال یک همتای فعال را قطع کند.

## محدوده و ایمنی

- پنل پیش‌فرض فعال نیست. فقط وقتی `PQTUNNEL_ADMIN_LISTEN` تنظیم شده باشد بالا می‌آید.
- آدرس باید IP حلقهٔ محلی باشد: `127.0.0.1:9090` یا `[::1]:9090`. آدرس wildcard یا عمومی رد می‌شود.
- هنگام فعال‌سازی، `PQTUNNEL_ADMIN_TOKEN` باید دست‌کم ۳۲ بایت داشته باشد. یک توکن تصادفی با آنتروپی بالا انتخاب و در فایل محیطی فقط-برای-root نگهداری شود؛ آن را در آرگومان خط فرمان قرار ندهید.
- پنل HTTP بدون TLS است، چون فقط روی loopback گوش می‌دهد. برای دسترسی از رایانهٔ دیگر از یک تونل مدیریتی رمزگذاری‌شده مثل SSH استفاده کنید؛ هرگز پورت پنل را مستقیماً به اینترنت منتشر نکنید.
- ورود از نشست تصادفی درون‌حافظه‌ای با انقضای ۱۲ ساعت استفاده می‌کند؛ کوکی HttpOnly و SameSite=Strict است و تغییر وضعیت به بررسی Origin و توکن CSRF نیاز دارد.
- پنل تنها داده‌های عملیاتی محدود را نشان می‌دهد؛ آدرس سوکت همتاها، مقادیر CIDR، محتوای بسته‌ها، گواهی‌ها و کلیدهای خصوصی را نمایش نمی‌دهد.
- تنها عمل تغییردهندهٔ وضعیت، قطع اتصال همتای انتخاب‌شده است. پنل سرویس systemd را راه‌اندازی/متوقف نمی‌کند و هیچ مسیر، sysctl، فایروال، NAT، گواهی یا کلید را تغییر نمی‌دهد.

## تنظیمات اختیاری

این دو متغیر در محیط فرایند daemon فعال‌سازی پنل را کنترل می‌کنند:

```ini
PQTUNNEL_ADMIN_LISTEN=127.0.0.1:9090
PQTUNNEL_ADMIN_TOKEN=replace-me
```

مقدار نمونهٔ توکن عمداً معتبر نیست و باید با یک راز تصادفی حداقل ۳۲ بایتی جایگزین شود. در صورت نبودن توکن کافی، daemon از فعال‌سازی پنل خودداری می‌کند. با حذف `PQTUNNEL_ADMIN_LISTEN` پنل کاملاً خاموش می‌شود؛ قرار دادن صرفِ توکن، شنونده‌ای باز نمی‌کند.

این پنل یک ویژگی مدیریتی اولیه در پروژهٔ آزمایشی است، نه سامانهٔ کامل مدیریت کاربران یا لاگ ممیزی. پروژه هنوز برای استفادهٔ تولیدی مورد تأیید نیست.
